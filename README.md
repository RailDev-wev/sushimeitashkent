# SUSHIMEI — сайт + Telegram Mini App

Один Next.js-проект работает и как обычный сайт, и как Mini App внутри Telegram-бота.
Онлайн-оплаты нет: заказ уходит сообщением в Telegram-группу, оператор перезванивает.

**Стек:** Next.js 16 (App Router), Tailwind 4, zustand (корзина), zod (валидация), grammY (бот). Без БД.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Без `.env.local` всё работает: заказ вместо Telegram печатается в консоль сервера.

## Структура

| Путь | Что там |
| --- | --- |
| `src/data/menu.json` | Меню: категории, позиции, цены, названия на ru/uz/en |
| `public/menu/` | Фото блюд: `<id позиции>.jpg/.webp/.png` подхватываются автоматически |
| `src/config/site.ts` | Телефон, адрес самовывоза, часы работы |
| `src/i18n/dictionaries/*.json` | Тексты интерфейса и бота |
| `src/app/[lang]/` | Страницы: меню и корзина/оформление |
| `src/app/api/order` | Приём заказа → сообщение в группу |
| `src/app/api/bot` | Webhook бота (`/start`, `/chatid`) |
| `src/components/Logo.tsx` | Временный текстовый логотип; заменить на настоящий |

### Меню
- `price: null` или `hidden: true` — позиция не показывается и не принимается к заказу.
- `pcs` — количество штук, выводится отдельно («8 шт»).
- `isNew: true` — бейдж «Новинка».
- Цены на сервере всегда берутся из `menu.json`, а не из браузера.
- Фото: положить файл в `public/menu/` с именем = `id`. После добавления фото нужен редеплой.
  Временно можно стянуть текущие фото из Clopos: `node scripts/fetch-clopos-images.mjs`.

### Внутри Telegram
Сайт сам понимает, что открыт в Telegram (`initData`), и тогда:
- вместо плавающей кнопки корзины — нативная MainButton, назад — BackButton;
- тема подстраивается под светлую/тёмную Telegram;
- имя подставляется из профиля, номер можно взять кнопкой «Взять номер из Telegram»;
- в заказ добавляется ссылка на Telegram клиента (подпись `initData` проверяется на сервере),
  а клиенту в бот приходит подтверждение.

## Подключение бота

1. Создать бота в @BotFather, получить токен.
2. Создать группу для заказов, добавить туда бота.
3. Скопировать `.env.example` → `.env.local` и заполнить `TELEGRAM_BOT_TOKEN`, `NEXT_PUBLIC_SITE_URL`, `TELEGRAM_WEBHOOK_SECRET`.
4. Задеплоить (Vercel: импорт репозитория + те же env-переменные).
5. Зарегистрировать webhook, кнопку меню, команды и описания:
   ```bash
   node --env-file=.env.local scripts/setup-bot.mjs
   ```
6. В группе отправить `/chatid`, полученное число (вида `-100…`) записать в `TELEGRAM_ORDERS_CHAT_ID`, редеплой.
